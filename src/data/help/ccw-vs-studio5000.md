# CCW and Studio 5000 at a glance
This game uses **Studio 5000** (Logix) instruction names, because they're short and they're what most ladder references use. Your work project may be on either.

- **Connected Components Workbench (CCW)** programs **Micro800** controllers (Micro820, 850, 870). It's free. Languages: ladder, function block, structured text. Instructions follow **IEC 61131-3**: direct and reverse contacts, set and reset coils, and timers and counters as function blocks (TON with IN/PT/Q/ET, CTU with CU/PV/Q/CV). It has a Micro800 simulator.
- **Studio 5000 Logix Designer** programs **CompactLogix** and **ControlLogix**. It's licensed. Instructions are XIC, XIO, OTE, TON with a TIMER tag, and so on, plus routines, tasks, user-defined types and add-on instructions.

## What carries over
Everything about scans, seal-ins, fail-safe stops, one-shots, timers, counters, state machines, alarms and scaling. Only the names and the editor change.
