# Stop before reset
Before resetting an overload, releasing an E-stop, or resetting a drive fault, put the mode switch at **Stop** (or OFF). Then fix the cause, reset, and return to the mode you want.

Why: with two-wire control or an Auto mode, the machine may restart the moment the reset happens.

## Safety
That's the procedure in our press operator guide. Fixing the cause usually means lockout/tagout first. See [[lockout-tagout]].
