# Lockout/tagout (LOTO)
Before hands go into a machine, every energy source is isolated and **locked**: the disconnect is opened and padlocked, stored energy is released, and the machine is tested to prove it won't start.

None of these are lockout:
- An E-stop. See [[e-stop]].
- A Stop button, or a mode switch at Stop.
- A contactor dropping out. It can weld shut. See [[contactor]].
- A PLC output turned off.

## Safety
Follow AmeriPro's written LOTO procedure for each machine. This game never replaces it.

## Real world
OSHA 29 CFR 1910.147 covers lockout in the US. Each worker puts on their own lock.
