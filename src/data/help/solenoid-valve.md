# Solenoid valve (Y)
A solenoid valve opens (or closes) when its coil is energized. Our press's **Y1** sprays wash water on the rings. On the wash rig, Y1 is the spray and Y2 the tank fill.

## Real world
- Check the valve's normal state: **normally closed** valves stay shut with no power, which is what you want for a water fill.
- Coils energized for a long time run hot; check the duty rating.
- The MWTP trailer uses air-operated valves with solenoid pilots, some set to **fail open** (XV-300 divert to waste) and some **fail closed** (XV-602 to the building).
