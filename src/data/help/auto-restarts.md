# Auto modes restart unattended
In Auto or Remote, a machine can start with **nobody at the panel**: a level rises, a PLC contact closes, a timer runs out, power returns. On our press, Remote lets the plant PLC start it through terminals 18/41.

## Safety
- Treat any machine in Auto or Remote as able to start at any time.
- Put the mode switch at Stop and lock out before working on it.
- A warning horn or light before an automatic start is good practice. Mission 2.11 adds one.
