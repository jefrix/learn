# learn

AmeriPro's learning projects. The first is **Control Room**, a browser game that teaches relay logic, then Allen-Bradley PLC ladder programming, then software skills, using our own equipment as the missions.

## Start here
- `PROMPT.md`: the brief to paste into Claude Code to build the game.
- `reference/screwpress/CONTROL_LOGIC.md`: our screw press panel's relay logic in plain text.

## Contents
| Path | What it is |
|---|---|
| `reference/screwpress/` | PJDL-302 screw press: control logic summary, the six wiring sheets, panel and nameplate photos, and copies of the operator guide and notes pages from the ameripro repo |
| `reference/mwtp/` | Electrical schematics, P&ID and design notes for the Mobile Water Treatment Plant concepts |
| `assets/` | AmeriPro logo |

The reference files are copies taken on 2026-11-21. The originals live in [jefrix/ameripro](https://github.com/jefrix/ameripro), where the screw press guide is maintained.

## Learning order
1. Relay logic
2. Allen-Bradley PLC programming (Connected Components Workbench and its Micro800 Simulator to start, Studio 5000 concepts after)
3. JavaScript core
4. Browser dev tools and debugging
5. Git beyond the basics
6. Game-loop thinking
7. Python, later
